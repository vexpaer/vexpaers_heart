# 制造资料与下单说明

每个板卡子目录均包含 Gerber/Excellon、BOM、贴片坐标、钻孔报告、ERC/DRC
报告，以及可直接上传 PCB 厂商的 fabrication ZIP。厂商应以 Gerber 和钻孔文件
为制造依据；KiCad/PDF 用于工程复核。

## Holter 主板下单参数

- 首批数量：5；成品尺寸：100.0 mm × 30.0 mm；板厚：0.8 mm；
- 4 层：L1 元件/信号、L2 完整 GND、L3 电源/信号、L4 信号；
- 铜厚：各层 1 oz；表面处理：ENIG、无铅；
- 最小线宽/间距：0.10/0.10 mm；最小成品孔：0.20 mm；
- 全部 253 个过孔均为 0.45/0.20 mm 普通电镀通孔；没有盲孔、埋孔、
  微孔、盘中孔、填孔或盖孔要求；
- 阻焊覆盖普通过孔；颜色可选，但不得覆盖 J3/J5 的底层 Pogo/SWD ENIG
  接触面；
- 主要元器件仅顶层 SMT。J3、J5 是底层裸露接触焊盘，不是待贴装器件；
- DNP：C10、C26、C27、C65、C66、R18、R19；首板不要安装这些位置；
- 天线区域四层禁铺铜、禁放过孔；不得删除或缩小板文件中的 keepout。

### RF 与阻抗 EQ

RF 走线在顶层、宽 0.18 mm，参考 L2 GND。该线宽只有结合实际介质厚度与
介电常数后才可能构成 50 Ω。下单时要求厂商：

1. 按其 0.8 mm 四层量产层叠计算并确认顶层 0.18 mm 单端线的阻抗；
2. 目标 50 Ω，建议容差 ±10%；
3. 如果标准层叠无法满足，必须暂停 EQ 并反馈可用层叠/线宽，不得自行改线宽、
   板厚或天线 keepout 后直接生产。

RF π 网络的 C65/C66 首板保持 DNP、R51 安装 0 Ω。最终值只能在整机外壳、电池
和人体邻近条件下做 VNA 测量后冻结。

### USB 与 microSD 限制

- USB 仅按 USB 2.0 Full-Speed 12 Mbit/s 使用，不支持 High-Speed；当前走线不是
  紧密耦合的 90 Ω 差分对。首板必须做枚举、持续传输和供电切换测试；
- microSD 首板固件先用 4 MHz SPI 初始化和压力测试，通过后再提高；初始建议
  上限 12 MHz；
- 不得因厂商 EQ 任意更换 0.8 mm 层叠、改变 RF/USB 走线或移动器件。

## USB-Pogo 底座下单参数

- 首批数量：5；成品尺寸：42.0 mm × 24.0 mm；
- 2 层、1.6 mm、1 oz、ENIG、无铅；
- USB-C、ESD/保护器件和指示灯按 BOM/CPL 贴装；
- Pogo 弹簧针与机械定位件由夹具结构决定，按装配图手工安装；
- 与主板接触顺序固定为 `VBUS / D- / D+ / GND`，不得镜像或调换。

## 安全标识与首板验证

主板和夹具上的 `DISCONNECT ELECTRODES BEFORE USB` / 互锁提示不得删除。
本设计没有患者侧 USB 隔离，连接人体电极时严禁连接 USB/Pogo；USB 导出或刷机
前必须先拔下整条电极线缆。

这是一套研究原型，不是医疗器械。任何人体连接之前，必须先在 ECG 模拟器和
患者等效假负载上验证输入漏电/偏置、RLD 稳定性、噪声、ESD 恢复和故障状态；
同时完成 RF、USB、microSD、电源温升、反向电流、电池极性及机械互锁验证。

详细证据和仍需实测的项目见 `docs/HARDWARE_AUDIT.md`。
